# Streckgubbe

Ett enkelt 2D-monsterfighting-spel i webbläsaren. Streckgubbe med hacka, malm, smältstation, blixtar och monster i grottor.

## Starta lokalt

Dubbelklicka `starta-spelet.bat`. Spelet öppnas på http://localhost:8765/index.html. Låt det svarta fönstret vara öppet medan du spelar.

Mer instruktioner finns i `LASMIG.md`.

## Molnmiljö

Använd `verktyg/moln-setup.sh` som Setup script i molnmiljöns inställningar. Filen har Unix-radslut (LF).
